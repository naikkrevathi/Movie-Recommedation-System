Description:

A content-based movie recommendation system that suggests similar movies using text analysis and similarity scoring.

Technologies Used:

•	Python 

•	Pandas 

•	NumPy 

•	Scikit-learn 

•	TF-IDF Vectorizer 

•	Cosine Similarity 

•	Difflib 

•	Google Colab

Features:

•	Recommends top 10 or top 30 movies based on user input. 

•	Combines multiple attributes like genre, cast, director, and keywords for better accuracy. 

•	Handles spelling mistakes using closest match logic. 

•	Fast and efficient similarity calculation using vectorized operations. 

Usage:

•	User enters a favorite movie name in the input. 

•	System finds the closest matching movie from dataset. 

•	Calculates similarity scores with all movies. 

•	Displays a list of recommended movies based on similarity ranking.
